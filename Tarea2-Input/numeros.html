Input Tipo Numerico


Volver al inicio

type="number"

  • Acepta unicamente valores numericos.
  • Muestra flechas arriba y abajo para cambiar el valor.
  • El atributo min define el valor minimo permitido.
  • El atributo max define el valor maximo permitido.
  • El atributo step define el intervalo de incremento.
input type="number" name="edad" min="1" max="120" step="1"

type="range"

  • Presenta un control deslizante para seleccionar un valor en un rango.
  • Se usa cuando el valor exacto no es critico, como volumen o brillo.
  • Los atributos min y max definen los extremos del rango.
  • El atributo value establece el valor inicial del deslizador.
input type="range" name="nivel" min="0" max="100" value="50"
