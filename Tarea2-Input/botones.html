Input Tipo Numerico


Volver al inicio

type="submit"

  • Crea un boton que envia los datos del formulario al servidor.
  • El destino del envio se define en el atributo action del formulario.
  • El atributo value define el texto visible en el boton.
  • Es el boton de envio mas comun en formularios HTML.
input type="submit" value="Enviar formulario"

type="reset"

  • Restablece todos los campos del formulario a sus valores iniciales.
  • No envia datos al servidor; solo limpia el formulario en el navegador.
  • El atributo value define el texto visible en el boton.
  • Util cuando el usuario quiere borrar lo escrito y empezar de nuevo.
input type="reset" value="Limpiar formulario"

type="button"

  • Crea un boton generico sin comportamiento predeterminado.
  • Su accion se define mediante JavaScript con el atributo onclick.
  • El atributo value define el texto visible en el boton.
  • Es diferente de submit porque no envia el formulario por defecto.
input type="button" value="Haz clic aqui" onclick="alert('Boton presionado!')"

type="image"

  • Crea un boton de envio usando una imagen en lugar de texto.
  • Al hacer clic envia las coordenadas X e Y del punto donde se hizo clic.
  • El atributo src indica la ruta de la imagen a mostrar.
  • El atributo alt proporciona texto alternativo si la imagen no carga.
input type="image" src="boton.png" alt="Tipos de Input" width="50px"
