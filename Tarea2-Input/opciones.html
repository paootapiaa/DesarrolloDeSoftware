Input Tipo Numerico


Volver al inicio

type="checkbox"

  • Muestra una casilla que puede estar marcada o desmarcada.
  • Permite seleccionar multiples opciones de forma independiente.
  • Se usa para aceptar terminos, preferencias o filtros.
  • El atributo checked hace que la casilla aparezca marcada por defecto.
input type="checkbox" name="tecnologia" value="html"

type="radio"

  • Opciones mutuamente excluyentes; solo se puede elegir una a la vez.
  • Todos los botones del mismo grupo comparten el mismo atributo name.
  • El atributo value define el dato que se envia al seleccionar esa opcion.
  • El atributo checked marca una opcion como seleccionada por defecto.
input type="radio" name="turno" value="manana"

type="color"

  • Abre el selector de colores del sistema operativo.
  • El valor se devuelve en formato hexadecimal, por ejemplo: #6c3fc5
  • Se usa para personalizar temas y configuracion visual.
  • El atributo value establece el color inicial del selector.
input type="color" name="colorFav" value="#6c3fc5"
