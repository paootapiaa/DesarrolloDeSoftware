Input Tipo Numerico


Volver al inicio

type="date"

  • Despliega un selector de fecha tipo calendario en el navegador.
  • El valor se envia en formato AAAA-MM-DD.
  • Se puede limitar el rango de fechas con los atributos min y max.
  • Util para registrar fechas de nacimiento, citas o eventos.
input type="date" name="nacimiento"

type="time"

  • Permite seleccionar una hora en formato HH:MM.
  • El navegador puede mostrar formato 12 o 24 horas segun configuracion.
  • Se usa para definir horarios de citas, reuniones o eventos.
  • Atributos comunes: min, max, step.
input type="time" name="hora"

type="datetime-local"

  • Combina fecha y hora en un unico campo de entrada.
  • No incluye informacion de zona horaria.
  • Ideal para reservas, registro de eventos y programacion de tareas.
  • El valor se envia en formato AAAA-MM-DDTHH:MM.
input type="datetime-local" name="evento"

type="month"

  • Permite seleccionar unicamente mes y anio, sin especificar el dia.
  • Util para periodos de facturacion, informes mensuales o vencimientos.
  • El valor se envia en formato AAAA-MM.
  • Atributos comunes: min, max.
input type="month" name="mes"

type="week"

  • Permite seleccionar una semana especifica dentro de un anio.
  • El rango va de la Semana 1 a la Semana 52 o 53 segun el anio.
  • Util para planificacion semanal y horarios academicos.
  • El valor se envia en formato AAAA-Www, por ejemplo: 2026-W15.
input type="week" name="semana"
