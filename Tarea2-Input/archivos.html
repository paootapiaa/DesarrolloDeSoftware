type="file"

  • Abre el explorador de archivos del dispositivo.
  • Permite seleccionar uno o varios archivos para subir al servidor.
  • El atributo accept filtra los tipos de archivo permitidos.
  • Para enviar archivos el formulario necesita enctype igual a multipart/form-data.
  • El atributo multiple permite seleccionar mas de un archivo.
input type="file" name="documento" accept=".pdf,.docx"

type="hidden"

  • Campo invisible para el usuario pero incluido al enviar el formulario.
  • Se utiliza para pasar datos de forma transparente, como identificadores de sesion.
  • Tambien se usa para enviar tokens de seguridad o IDs de registros.
  • El usuario no puede ver ni modificar este campo desde la pagina.
input type="hidden" name="idUsuario" value="12345"

Este campo no se ve en la pagina pero si existe en el codigo fuente:

input type="hidden" name="idUsuario" value="12345"
