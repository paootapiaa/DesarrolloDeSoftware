Input Tipo Numerico


Volver al inicio

type="text"

  • Es el tipo predeterminado de la etiqueta input.
  • Permite escribir cualquier texto en una sola linea.
  • Se usa para nombres, titulos y datos de texto libre.
  • Atributos comunes: placeholder, maxlength, required.
input type="text" name="nombre" placeholder="Ingresa tu nombre"

type="password"

  • Oculta los caracteres mostrando puntos o asteriscos.
  • Se usa para contrasenas y datos confidenciales.
  • El navegador puede ofrecer opcion para mostrar u ocultar el texto.
  • Atributos comunes: minlength, maxlength, required.
input type="password" name="clave" placeholder="Contrasena"

type="email"

  • Valida que el texto tenga formato de correo electronico.
  • El formato requerido es: usuario@dominio.com
  • En dispositivos moviles muestra teclado con el simbolo @.
  • Atributos comunes: placeholder, required, multiple.
input type="email" name="correo" placeholder="usuario@ejemplo.com"

type="tel"

  • Disenado para ingresar numeros de telefono.
  • En dispositivos moviles despliega el teclado numerico.
  • No aplica validacion automatica de formato en el navegador.
  • Se recomienda el atributo pattern para validar el formato.
input type="tel" name="telefono" placeholder="+593 09 999 9999"

type="url"

  • Valida que el valor ingresado sea una URL valida.
  • La URL debe comenzar con http:// o https://
  • Util para solicitar direcciones de sitios web o perfiles.
  • Atributos comunes: placeholder, required, pattern.
input type="url" name="sitio" placeholder="https://www.ejemplo.com"

type="search"

  • Campo semanticamente pensado para busquedas.
  • Algunos navegadores muestran un boton X para borrar rapidamente.
  • Visualmente similar a type text pero con distinto significado semantico.
  • Atributos comunes: placeholder, required.
input type="search" name="buscar" placeholder="Buscar..."
